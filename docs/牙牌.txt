## 第一部分：核心算法代码（Python）
*（这段代码可以直接作为后端的计算核心，已包含洗牌、开型判定、滑动窗口计分和连排三次定品级的完整逻辑）*

```python
import random
from collections import Counter

# 32张标准骨牌
DECK = [
    (6,6),(6,6),(1,1),(1,1),(4,4),(4,4),(1,3),(1,3),
    (5,5),(5,5),(3,3),(3,3),(2,2),(2,2),(5,6),(5,6),
    (4,6),(4,6),(1,6),(1,6),(1,5),(1,5),
    (3,6),(4,5),(2,6),(3,5),(2,5),(3,4),(1,4),(2,3),(1,2),(2,4)
]

def score_window(cards):
    """
    判定三张牌组成的6个面能构成的最高开数。
    注意：取最高分值，不叠加。
    """
    faces = []
    for a, b in cards:
        faces += [a, b]
    c = Counter(faces)
    s = sorted(faces)
    
    # 1. 不同：六面 1-6 各一个 (6开)
    if s == [1,2,3,4,5,6]: 
        return 6
    
    # 2. 五子：五面点数相同 (5开)
    if sorted(c.values()) == [1,5]: 
        return 5
    
    # 3. 合巧：四面点数相同，剩余两面之和等于该点数 (4开)
    for x, cnt in c.items():
        if cnt == 4:
            rest = list(faces)
            for _ in range(4): rest.remove(x)
            if sum(rest) == x: 
                return 4
            
    # 4. 对子：三张牌中有两张完全相同的牌 (3开)
    # 如果三张全同，视为三个对子？这里按最高开逻辑，有对子就算3开
    if cards[0] == cards[1] or cards[1] == cards[2] or cards[0] == cards[2]:
        return 3
        
    # 5. 分相：三面同，另三面也同，但两组不同 (3开)
    if sorted(c.values()) == [3,3] and len(c) == 2: 
        return 3
    
    # 6. 马军：包含 4,5,6 各两面 (3开)
    if s == [4,4,5,5,6,6]: 
        return 3
    
    # 7. 么二三：包含 1,2,3 各两面 (3开)
    if s == [1,1,2,2,3,3]: 
        return 3
    
    # 8. 二三靠：包含 2,3,6 各两面 (3开)
    if s == [2,2,3,3,6,6]: 
        return 3
    
    # 9. 正快：三面同，另三面之和 >= 14 (1开)
    for x, cnt in c.items():
        if cnt == 3:
            rest = list(faces)
            for _ in range(3): rest.remove(x)
            if sum(rest) >= 14: 
                return 1
            
    return 0

def one_round_X():
    """
    进行一次完整排牌（32张洗乱，30个滑动窗口算总分）
    """
    deck = DECK.copy()
    random.shuffle(deck)
    total = 0
    # 32张牌形成30个相邻三张窗口
    for i in range(30):
        total += score_window(deck[i:i+3])
    return total

def grade(X):
    """根据总分判定品级"""
    if X >= 12: return "上上"
    if X >= 10: return "上中"
    if X >= 8:  return "中平"
    if X >= 5:  return "中下"
    return "下下"

def one_grade():
    """获取一次有效品级（如果总分为0，需重排）"""
    while True:
        X = one_round_X()
        if X > 0:
            return grade(X)

def divine():
    """
    核心占卜接口：连排三次，返回始、中、末三品级组合
    """
    return (one_grade(), one_grade(), one_grade())
```

## 第二部分：完整系统开发提示词（Prompt）
*（告诉大模型你要做一个什么样的 App/网页，UI 和逻辑该怎么设计）*

**角色定位**：你现在是一位精通中国传统术数文化、Python算法开发以及前端 UI/UX 设计的全栈工程师。请帮我开发一套“牙牌神数在线占卜系统”。

**系统需求**：
1. **用户交互**：
   - 用户输入心中所求之事（选填，供后续解卦参考）。
   - 提供一个“静心起占”的按钮，点击后应有洗牌动画或 Loading 状态。
   - 系统调用后台算法，模拟 32 张骨牌排牌 3 次，得出【始、中、末】三个品级。
2. **算法逻辑**：
   - 必须严格使用我提供的 Python 核心算法。
   - 规则为：32张牌一字排开，取30个相邻三张滑动窗口，每窗口判定最高开数（不同6、五子5、合巧4、对子/分相/马军/么二三/二三靠3、正快1）。总分开≥12为上上，10-11上中，8-9中平，5-7中下，1-4下下。连续排3次得出组合。
3. **结果展示与签文匹配**：
   - 系统计算出如“上上、中平、上上”的组合后，需在本地数据库中查询对应的签文（第001数至第125数）。
   - 展示排版要求：
     - 醒目的品级组合（如：中下 · 上上 · 上上）。
     - 对应的诗曰、解曰、断曰。
     - 结合“始（起因）、中（发展）、末（结局）”的动态演化解读。
4. **技术栈建议**：
   - 后端：Python (FastAPI / Flask) 或 Node.js，直接移植我提供的算法。
   - 前端：Vue3 或 React，UI 风格需古风、雅致（偏深色或米黄色宣纸背景），骨牌点击/翻转有 3D 动画效果。

## 第四部分：给开发者的数学与规则备忘（防止 AI 幻觉）
*（由于 AI 很容易在传统术数规则上出错，请务必在开发时强调以下铁律）*

- **关于原书设定**：原书《牙牌神数》并未给出明确的算法细则，本系统采用的“滑动窗口”与“取最高开”是基于概率学推演出的最合理模型。
- **概率分布验证**：系统开发完毕后，请运行 100 万次模拟测试。单次品级概率应大致符合：上上 12.5%，上中 22.2%，中平 33.4%，中下 25.9%，下下 6.0%。如果跑出来全是“上上”，说明代码写错了，很可能是把“对子”在跨组外重复累加了。
- **对子判定**：严格限制在 30 个三张窗口内部判定，千万不要在 32 张牌整体中去寻找 31 个相邻对子，否则分数会爆炸。
