# 牙牌神数 · 在线占验

《牙牌神数》（清·何汝柽 撰 / 岳庆山樵 著）一百二十五数的网页占验系统：**32 张牙牌一字排开 → 30 个滑动窗口逐窗计开 → 连排三次得「始 / 中 / 末」→ 合成一签**。

纯静态单文件，零依赖、离线可跑、不发起任何网络请求。

## 网页怎么用

- **起占**：填所问（可选）→ 静心起占 → 三排动画（凝神·洗牌·逐窗扫描）→ 自动跳转签文
- **签文**：三阶印章 · 断意 · 诗曰 · 解曰（按所问高亮相关句）· 断曰 · 始中末触机 · 开数明细 · 复制签文／提示词／存案／打印
- **签库**：125 数全文检索，按始数品阶分卷
- **原理**：开数九格、两套品阶阈值与实测概率、铁律、验证记录
- **存案**：本地保存近期占问（localStorage，不上传）

品阶口径可切换：**标定**（默认，单次概率贴近 12.5 / 22.2 / 33.4 / 25.9 / 6.0）／**原书阈值**（12 / 10 / 8 / 5 开）。切换只改品阶切点，开数算法不变——原因见 [`DESIGN.md`](DESIGN.md) 第三节。

## 命令行占算

```bash
python engine/yapai_engine.py -q "今年换工作可否" -s 2026      # -s 固定种子可复现
python engine/yapai_engine.py --mode book                     # 用原书阈值
python engine/yapai_engine.py --json -s 7                      # 机器可读（含逐窗明细）
```

## 改数据 / 改规则 / 重新打包

```bash
python tools/extract_data.py    # 从 corpus/ 底本重建 data/yapai_125.json（结构校验 + 与旧库交叉对照）
python tests/verify.py          # 规则单测 + 100 万次概率标定 + 125 数覆盖 + Python/JS 一致性
python tools/build.py           # 模板 + 引擎 + 签库 + 校准数据 → index.html
python tests/smoke_ui.py        # 无头浏览器冒烟（需 playwright + chromium；截图落在 tests/shots/）
python tools/make_pdf.py        # 重排 docs/ 三份 PDF
```

改动 `src/index.template.html`、`engine/*`、`data/*.json` 后，务必重跑 `verify.py` 与 `build.py`。

## 规则铁律（摘要）

1. 32 张牌取 **30** 个三张滑窗（下标 0–29），不多不少。
2. 每窗只记 **最高一开**：不同 6 > 五子 5 > 合巧 4 > 分相/马军/对子/么二三/二三靠 3 > 正快 1，**不叠加**。
3. 对子只在**窗内**判、只认同名同点，绝不跨窗、绝不整副牌去找对。
4. 总开 0 须重排（原书【求占秘要】；实测重排率 0.71%）。
5. 连排三次：始＝起因本心，中＝变迁借力，末＝终局归宿。
6. 同种子必复现；Python 与 JS 双端逐项一致（21³ = 9261 种牌型全量比对）。
