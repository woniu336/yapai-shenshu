占法 · 开数九格

三十二张牙牌（文牌十一种各两张、武牌十张）洗乱，一字排开，取三十个相邻三张的滑动窗口；每窗只记最高一开，互不叠加；三十窗之和为一次「总开」。

开数分值成开规则

品阶 · 五等

品阶标定口径（默认）原书阈值单次概率（实测）

原书以「十二开以上为上上、十至十一开为上中、八至九开为中平、五至七开为中下、一至四开为下下」定品。 依九格逐窗计开、三十窗相加之后，实测分布会严重偏上（上上约占 51%）。 故默认采用「标定口径」：开数算法一字不改，仅把四个品阶切点按其目标概率分位对齐， 使单次品阶概率回到 12.5 / 22.2 / 33.4 / 25.9 / 6.0%。可在起占处随时切回「原书阈值」。

铁律 · 防止走样

  1. 三十二张牌，取三十个三张滑窗（下标 0–29），不多不少。
  2. 每窗取最高一开：不同6 > 五子5 > 合巧4 > 分相/马军/对子/么二三/二三靠3 > 正快1。同窗多格并存时不得累加。
  3. 「对子」只在窗内判定两张完全相同的牌，绝不跨窗、不整副牌去找对。
  4. 总开为 0 时按原书【求占秘要】须重排，不入品。
  5. 连排三次：初数＝始（起因本心）、中数＝中（变迁借力）、末数＝末（终局归宿），三数合成一签。
  6. 同一随机种子必须复现同一局；引擎 Python 与 JS 同口径，21³ 组合全量比对通过。
